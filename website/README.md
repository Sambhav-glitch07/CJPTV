## 🚀 How to Publish to GitHub (Free & Instant)

### Option 1: Direct GitHub Pages Deployment (Easiest)

1. Create a new repository on [GitHub](https://github.com/new) (e.g. `cjptv-news` or `vibhagupta13572.github.io`).
2. Upload the `index.html` file from this `website/` folder directly to the root of your GitHub repository.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your website will be live worldwide in seconds at:
   ```
   https://<your-username>.github.io/<repo-name>/
   ```

## 🌐 Connecting Custom Domain (cjptv.in)

1. In your GitHub repository, go to **Settings** > **Pages**.
2. Enter `cjptv.in` in the **Custom domain** field and click **Save**.
3. In your DNS provider (e.g. GoDaddy, Namecheap, Cloudflare), add these `A` records pointing to GitHub Pages:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`

4. Enable **Enforce HTTPS**.
